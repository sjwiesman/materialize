A search experience whose documents, attributes, and embeddings track their source data, with hybrid retrieval at query time.

## What this example will hold

Source tables for a catalog; views for document bodies and filterable attributes; an embedding step that runs only for changed rows; a vector store fed by a sink; a query path that combines vector hits with live structured filters.
