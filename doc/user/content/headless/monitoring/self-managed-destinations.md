To send metrics and logs to a platform you already run, a guide is available for
each destination:

- [Datadog](/operate/monitor/self-managed/datadog/)

- [Honeycomb](/operate/monitor/self-managed/honeycomb/)

- [OpenTelemetry](/operate/monitor/self-managed/opentelemetry/), for any other OTLP
  endpoint, including your own collector.

- [Google Cloud Monitoring](/operate/monitor/self-managed/google-cloud-monitoring/)

- [Prometheus remote
  write](/operate/monitor/self-managed/prometheus-remote-write/), for Mimir,
  Amazon Managed Prometheus, Grafana Cloud, or a Thanos you run elsewhere.
