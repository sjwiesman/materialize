# Introduction

This book teaches you `mz-deploy`, the declarative SQL project tooling for
Materialize. Read it front to back the first time; come back to individual
chapters as a reference once you're shipping.

The book is in three parts. Part I gets you from zero to your first
promoted deployment. Part II walks the project lifecycle one phase at a
time. Part III covers the concepts that change how you design your
projects: stable API schemas, profiles, and variables. The appendices are
the per-command reference and a glossary.
